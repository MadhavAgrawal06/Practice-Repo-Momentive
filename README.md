## What is GitHub?
GitHub is a website where we can store our code online. It also helps multiple people work on the same project together without messing up each other's work.

---

## What is a repository?
A repository is basically a folder for project on GitHub. It keeps all the files and also remembers every change we ever made.

---

## What is a branch?
A branch is like a copy of the project where we can try things out. Whatever we do there won't affect the main project until we decide to merge.

---

## What is a commit?
A commit is just saving the changes with a small note saying what you did.

---

## What is a Pull Request?
A Pull Request is when you say "Hey, I made some changes, can someone check and approve it?". It let others review your work before it goes into the main code.

---

## Why should we not push passwords/secrets?
We should not push password and secrets because once its on GitHub,anyone can see it. Someone could use those passwords to get into systems they shouldnot.
It is a security risk.

---

## What checks should be done before raising a PR?
1. Make sure the code is actually working.
2. Double check no passwords or keys are included.
3. Keep only the files that are needed.
4. Write clear commit message.
